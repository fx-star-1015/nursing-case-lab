# 护理研习室

内外科护理案例学习网站。纯静态 HTML、CSS 和 JavaScript，无需 GPT 账号、API Key 或构建工具。

## 功能

16 个专题、关键词搜索、案例作答、参考解析、自评、复盘笔记、待复习清单和学习进度。记录保存在访问者自己的浏览器中，可导出和导入。

## 发布到 GitHub Pages

将本目录内容放到仓库根目录，进入仓库 Settings → Pages，在 Build and deployment 中选择 Deploy from a branch，选择 main 分支和 /(root)，保存。发布地址以 Pages 页面显示的地址为准。

所有资源均使用相对路径，兼容用户名.github.io/仓库名/这样的项目地址。

## 本地运行

直接打开 index.html，或在本目录运行 python -m http.server 8000 后访问 http://localhost:8000。

## 学习记录迁移

在原站点导出学习记录，再在新站点导入。不同域名的浏览器存储不会自动共享。

## 内容边界

16 个新编教学案例，来自讲义正文定向蒸馏；非学校官方题库，未覆盖全部PDF和图片病例。来源与核对信息可在网站的“内容与来源”中查看。仅供学习，非临床诊疗建议。

## 托管边界

此版本是免费学习静态站，没有服务器账号体系、云端笔记或付费权限。GitHub Pages 不应用于运营主要提供商业交易或商业SaaS的网站；若升级收费服务，保留GitHub作源码管理，另选后台托管。

https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

未附开源许可证；不代表原始讲义版权已获公开再利用授权。仓库不包含原始讲义、身份信息或任何服务密钥。


## 学习路径 v2

保留原有填写框，增加：练习 → 本题人工核对 → 诊断与鉴别 → 实验室与辅助检查 → 治疗原则 → 护理与复评 → 回原题修订。

16专题共64个阶段，208条学习要点，24张补充整理卡，96项病例核对。内容为原讲义选段的重新组织，不是官方评分标准或完整教材。每个阶段与卡片保留来源编号及Word非空段落锚点。

核对采用人工标记：尚未核对、已写到、待补充、本题不适用。不使用关键词自动判分。薄弱点连接到相应学习阶段；学习页保留原题；学习笔记不自动覆盖答案。回题可对照初答并保存最近5个修订版本。学习记录导出/导入包含核对状态和阶段标记。


## 知识对照 v3

四阶段学习主体改为具体知识对照表：369条事实行，区分表现/数值、意义/目标及适用条件/例外。可切换对照阅读或遮住细节逐项回忆；每行可标记记得/再记。原有指导语折叠为补充提示。

材料覆盖页列出23份Word及尚未处理的PDF/图片。事实表为选段转写，不能当作完整教材或全部材料已处理。数值以明确标注的讲义口径呈现，错误单位及可疑绝对表述不直接作为执行规则。


## 学生界面 v4

学习页改为病种目录、四阶段页签和分组知识清单。来源与编制信息退出主界面，原题、草稿与核对流程保留。

已按提供的人卫第6版《内科护理学》第五章重写泌尿系统10个单元，并关联《基础护理学》尿标本、出入量及排尿护理选段；扫描/OCR底稿仅留在本地 work/，不随站点发布。其余15个专题仍使用上一版讲义内容，尚未逐章完成教材补全，不应宣称三本教材已全覆盖。治疗相关旧版固定剂量、疗程及存在争议的通则未照搬，补充参考见各学习页“参考资料”。

笔记按病种与阶段分别保存；旧阶段笔记在慢性肾脏病对应阶段保留可读，导入导出包含新笔记和回忆标记。


## 细节补充 v5

泌尿系统50个知识点附按需展开的细节补充，共105条数值、机制、示例、适用条件与易混说明。所有数值保留单位和时间/人群等条件，主要阈值对照教材及列明年份的专业指南。细节参与阶段搜索；回忆模式先隐藏答案及其补充，展开后才可查看。未扩充其他15个专题的教材细节。


## 学生界面 v6

卡片按人卫第6版内外科目录排序，合并专题按首先涉及的章节放置。两类独立学习标记：completed表示已完成，done沿用已掌握含义；浏览器保存及导入导出均兼容旧记录。界面改为淡紫色；正文删除教材/讲义口径等编制措辞，来源留在参考资料中。
