# ice冰冰·高分学姐团

内外科护理学习网站。静态 HTML、CSS 和 JavaScript，无需 GPT 账号、API Key、安装或构建工具。学习咨询：ICEICE20250901。

## 教学路径

知识学习置于练习之前：共性框架 → 个性对照 → 回忆背诵 → 案例选用 → 核对修订。

- 共性框架提取本系统可复用的观察、护理问题与答题主干。
- 个性对照按诊断、检查、治疗、护理筛选，比较疾病、阶段、机制、数值与限制条件。
- 回忆分“背共性”“辨个性”，答案可展开，逐项标记记得或再记。
- 案例保留填写框；展开要点后自行确认、补充和修订，不自动判分。

16个系统包含70条共性框架、99组对照、393条差异内容、64道原创变式。原16个专题作答及解析继续保留。泌尿病种的既有细节层可从学习页“按病种查阅”进入。

## 材料与核查范围

按本地23份Word的全文抽取结果建立168项教学验收映射，原教学单元、横向整理、护理问题与原题学习目标均有对应落点。另核对相关病例图、独立护理诊断矩阵、循环用药图和部分人卫教材页。该映射表示教学目标已重组，不等于三本教材全书或所有原图逐字复刻。

教材与病例图只在本地核查，仓库不包含原始讲义、扫描页或OCR底稿。网站采用重新组织的学习表达和原创练习；来源段落与权威补充资料可在学习页“参考资料”查看。数值保留单位及适用条件，存在冲突的旧药量、固定操作和绝对化规则未直接恢复为通用指令。

## 学习记录

作答、笔记、回忆标记、核对勾选及“已完成／已掌握”保存在访问者当前浏览器。不同浏览器和域名不会自动同步；可以导出JSON，再导入迁移。兼容早期版本的专题答案、泌尿病种笔记和核对记录。没有云端教师后台或账号体系。

## 部署与本地运行

将本目录文件放在GitHub仓库根目录；Settings → Pages → Deploy from a branch → main → /(root)。所有资源使用相对路径，支持项目站点地址。

也可直接打开index.html，或运行 python -m http.server 8000 后访问localhost:8000。

主要文件：curriculum-data.js 为教学内容，curriculum.js 和 curriculum.css 为新学习界面；data.js、app.js、review*、detail* 保留原题、记录和深入病种学习。
